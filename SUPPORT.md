## Report a reproducible issue

Use the GitHub issue templates for bugs, feature requests, or documentation problems.

Include:
- The affected service directory.
- Operating system and runtime versions.
- Exact command or request method/path.
- Expected and actual behavior.
- Sanitized error output and reproduction steps.
- The affected commit or deployment, when known.

Remove credentials, tokens, personal data, private farm records, addresses, and uploaded images before posting publicly.

## Security reports

Do not publish exploitable security issues in a public issue. Follow [SECURITY.md](SECURITY.md) and contact the repository owner privately through GitHub's available security reporting controls.

## Agricultural and model limitations

Model results are not guaranteed diagnoses or official agronomic recommendations. For crop disease, pesticide, fertilizer, irrigation, food safety, or other consequential decisions, consult qualified local experts and verify recommendations against current local guidance.

## Feature requests

Explain the user problem, affected audience, proposed behavior, constraints, and how the change can be validated. For machine-learning requests, include dataset provenance and the intended evaluation approach.
